# 4. 自测与设计还原

> **主图位置：** `diagrams/04-self-test.svg` ← `docs/diagrams/04-self-test.excalidraw`

![自测与设计还原](/diagrams/04-self-test.svg)

## 目标

在打扰评审人之前，自己先当一次「严格的验收人」。

## 默认检查顺序

1. **功能：** 主路径点一遍；空态 / 错误态若存在也看一眼
2. **设计还原：** 对照 Figma（间距、字号、颜色、对齐）；不确定就标注「待设计确认」
3. **响应：** 至少看一个窄屏宽度
4. **工程：** lint / typecheck / build 本地绿

**为什么先自测：** Review 时间是公共资源；带明显低级问题的 PR 会消耗信任。

## 降级

没有设计稿 → 按 issue 文字验收，并在 PR 写明。  
没有预览 → 准备前后截图（下一章用）。
