# 4. 自测与设计还原

> **主图位置：** `diagrams/04-self-test.svg`

![自测与设计还原](/diagrams/04-self-test.svg)

## 目标

在打扰评审人之前，自己先当一次「严格的验收人」。

## 默认检查顺序

1. **功能：** 主路径点一遍；空态 / 错误态若存在也看一眼
2. **设计还原：** 对照 Figma（间距、字号、颜色、对齐）；不确定就标注「待设计确认」
3. **响应：** 至少看一个窄屏宽度
4. **工程：** lint / typecheck / build 本地绿

**为什么先自测：** Review 时间是公共资源；带明显低级问题的 PR 会消耗信任。

## 对照教具练习

若你在做第 3 章的 `feat/add-onboarding-task`：

| 检查 | 怎么过 |
| --- | --- |
| 功能 | 刷新页面，新默认任务出现在列表里；勾选/添加仍正常 |
| 设计 | 本教具无设计稿 → PR 写明「无设计稿，按练习卡验收」 |
| 响应 | 把窗口缩到约 375px 宽，列表与输入框仍可用 |
| 工程 | `npm run app:build` 通过 |

准备一张**改前 / 改后**截图（同浏览器宽度），下一章贴进 PR。

## 降级

没有设计稿 → 按 issue / 练习卡文字验收，并在 PR 写明。  
没有预览 → 准备前后截图（下一章用）。

## 检查清单

- [ ] 主路径自己点过，没把「顺手发现的小问题」留给评审人猜
- [ ] 窄屏看过一眼
- [ ] `npm run app:build` 绿
- [ ] 截图或预览链接已备好
