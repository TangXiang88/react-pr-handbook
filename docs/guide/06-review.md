# 6. 评审与修改

> **主图位置：** `diagrams/06-review.svg` ← `docs/diagrams/06-review.excalidraw`

![评审与修改占位](/diagrams/06-review.svg)

## 目标

把 Review 当成协作，而不是「被挑刺」。

## 默认做法

| 评论类型 | 你怎么做 |
| --- | --- |
| 必须改（bug / 规范 / 需求不符） | 改代码 + 回复已处理 |
| 建议（可讨论） | 采纳或简短说明不采纳原因 |
| 提问 | 先回答，再决定是否改 |

推送修正后，**回复线程**，让评审人不用翻 diff 猜你有没有改。

**为什么要回复：** 异步协作里，沉默 = 状态不明，合并会被拖住。
