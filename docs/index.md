# react-pr-handbook

给初级前端的入职协作手册：从拉起 React 项目到合入第一个规范 PR。

## 怎么读

1. 先读 [默认假设与降级](./guide/00-assumptions) —— 对不上的条款按降级做。
2. 按章节顺序走完闭环；**每章先看主图**，正文只解释图上的节点。
3. 对照仓库里的 `examples/app` 动手，不要只停留在文字。

## 闭环一览

| 章 | 你走完时应能做到 |
| --- | --- |
| [总览地图](./guide/01-map) | 说出从接到任务到合并的主路径 |
| [拉起项目](./guide/02-setup) | 本地跑起示例并理解目录 |
| [接任务改代码](./guide/03-change-code) | 在约定目录里改出一小步可演示的改动 |
| [自测与设计还原](./guide/04-self-test) | 自己验证后再打扰评审人 |
| [开 PR](./guide/05-open-pr) | 提交一份信息完整、可预览/可截图对照的 PR |
| [评审与修改](./guide/06-review) | 正确回应评论并推送修正 |
| [合并与发布](./guide/07-merge-release) | 知道合并后发生什么、你还要盯什么 |
| [常见翻车](./guide/08-pitfalls) | 避开初级最常踩的坑 |

> 主图在各章顶部。风格约定见仓库内 `docs/diagrams/README.md`；当前 SVG 与章节内容对齐，可用 Excalidraw 再回填源文件。
